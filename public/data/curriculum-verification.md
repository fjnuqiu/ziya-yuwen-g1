# 一年级上册语文内容核验

核验日期：2026-10-23。用于家庭同步学习，不以第三方网站旧版字表替代学校教材。

## 最终依据与范围

- 最终依据：[人教社官方在线电子书《义务教育教科书·语文 一年级上册》](https://book.pep.com.cn/1211001101241/mobile/index.html)，封面标注教育部审定 2024，共 118 个电子页面。
- 已直接打开官方浏览器，目视核对目录、印刷页 105—107 的识字表，以及放大后的印刷页 108 写字表。目录页码、课次顺序和字表以当前官方展示为准。
- [当前官方写字表原图（印刷第 108 页）](https://book.pep.com.cn/1211001101241/files/mobile/114.jpg?260811094231)用于逐项放大复核。图片参数是本次页面实际使用的版本标识，不推断其为出版日期。
- 同时从国家智慧教育平台公开资源下载了同名 2024 教材 PDF 作为文本提取中间资料。该 PDF 的目录与绝大多数字表一致，但存在下面列出的版本差异，因此没有把它直接当作最终字表。
- [国家智慧教育平台 PDF 提取辅助来源](https://r2-ndr.ykt.cbern.com.cn/edu_product/esp/assets/1c73b348-e8b6-47d6-84b0-6dbacbe28268.pkg/%E4%B9%89%E5%8A%A1%E6%95%99%E8%82%B2%E6%95%99%E7%A7%91%E4%B9%A6%20%E8%AF%AD%E6%96%87%20%E4%B8%80%E5%B9%B4%E7%BA%A7%20%E4%B8%8A%E5%86%8C_1725097498841.pdf)。只在临时目录作核验，不放入平台或分发整册。

覆盖 8 个单元的 14 课汉语拼音、8 课集中识字、10 课阅读和 8 个语文园地，共 40 个按课本顺序排列的学习节点。覆盖正式识字表、写字表、拼音总表及相关拼写、辨音、笔顺知识。开学教育、快乐读书吧、口语交际、日积月累及和大人一起读中的其他汉字不自动提高为新增会写字，避免让孩子负担超过教材要求。

平台的组词、发音提示、书写提示、要点和测验均为自编辅助内容；没有摘录完整课文。汉字的认读与会写分别记录，识字字表中未列入写字表的字不自动变成必默写任务。

## 当前官网与辅助 PDF 的差异

| 位置 | 辅助 PDF | 当前人教官网（最终采用） |
| --- | --- | --- |
| 识字表·语文园地八 | 牛 羊 爪 **旦** 拼 音 | 牛 羊 爪 **元** 拼 音 |
| 写字表·语文园地四 | 去 年 | **个 去** |
| 写字表·9 乌鸦喝水 | 只 个 多 石 出 | **只 多 办 石 出** |
| 写字表·语文园地八 | 牛 羊 果 白 | **牛 羊 爪 白** |

这意味着：当前版本中“年、果”仍在识字表中，但不在本册 100 个会写字中；“办、爪”是会写字；“个”的会写要求安排在语文园地四。不能混用不同公开版本的要求。若孩子学校的实物课本与上述不同，应以实物课本再核对，并单独建立版本，不能静默混合。

## 计数及去重

- 识字：280 个不同汉字。
- 认读项目：284 条。额外 4 条是教材蓝色标出的多音复习：四季的“地 de”、乌鸦喝水的“着 zháo”、雨点儿的“数 shǔ”和“长 zhǎng”。它们不计入 280 个新增汉字，但应保留在相应课次。
- 写字：100 条、100 个不同汉字；已程序校验无遗漏式重复。
- 拼音：63 个基础项目，包含 23 个声母、24 个韵母、16 个整体认读音节。
- 24 个韵母细分：6 个单韵母，8 个复韵母，1 个特殊韵母 er，5 个前鼻韵母，4 个后鼻韵母。
- 40 个节点的 `order` 为连续 1—40；`page` 为书本印刷页码；`sourcePages` 为该节点相关正文页，不是翻页器序号。总表来源页另存于 `book.sourceTables`。

## 拼音及字音处理

当前 `notes` 已涵盖：

| 内容 | 首次/主要节点 |
| --- | --- |
| 四线三格、四声变化、先听后读再写 | a o e |
| i 标调去点、ü 两点、u/ü 区别 | i u ü |
| 两拼：声母轻短、韵母响亮 | b p m f |
| n/l 区分；n、l 与 ü 拼写保留两点 | d t n l |
| 三拼与介母 | g k h |
| j/q/x 与 ü 相拼省略两点，仍按 ü 发音 | j q x |
| 平舌/翘舌；声母与整体认读音节区别 | z c s、zh ch sh r |
| y/w、yi/wu/yu，以及 yu 的两点规则 | y w |
| 复韵母连贯发音及标调 a、o、e 优先 | ai ei ui |
| iu/ui 区分及调号位置 | ao ou iu |
| ie/ei、ye/yue、j/q/x 与 üe、nüe/lüe | ie üe er |
| 前鼻韵母、yuan/yin/yun、üan/ün 拼写省点 | an en in un ün |
| 后鼻韵母、an/ang、en/eng、in/ing、ying | ang eng ing ong |
| 23 声母、24 韵母、16 整体认读音节统整 | 语文园地四 |
| 轻声、儿化、一/不变调、多音字随课区分 | 对应课次及园地 |

- `toneForms` 表示调号位置与带调认读练习；声母的该数组为空，不能对声母单独标四声。
- er 仅列常见的 ér、ěr、èr，不生成不常用的第一声来冒充常用词。
- 韵母的四声写法不是“每一种拼写都能独立当常用词”的声明。正式拼读与应用小测应使用有效音节，并说明自编题目。
- 单字读音以教材字表为准，例如：子 zǐ、巴 bā、友 yǒu；句子、尾巴、朋友中的相应字可能读轻声，已放在课次说明中，不能用轻声词的读音覆盖单字字表。
- 本册“谁”按官方标注为 shuí；“爪”按本册标注为 zhuǎ；“只”在乌鸦喝水中按 zhī。
- `polyphoneReview: true` 仅标记上述 4 条重复认读项目，保留原有课次。

## 核验方法与边界

1. 用 pypdf 提取辅助 PDF 目录、字表和拼音页面。PDF 为 118 页，印刷页 p 对应该辅助 PDF 的第 p+5 页。
2. 识别并转换其自定义拼音字体产生的编码字符（如 Q/W/A/S 对应 ā/á/ǎ/à），再逐项处理轻声及多音字。最终 JSON 不保留这些编码字符。
3. 在官方电子书上逐页对照目录及 105—108 页，发现并修正上表 4 处差异；写字表放大核对上、中、下段。
4. 程序断言 40 节、284 个认读项目、280 个不同认读汉字、100 个不同会写汉字和 63 个拼音项目；检查所有认读和写字项目均有字音，且没有未转换的大写编码字符。
5. 自编书写提示提供观察和记忆线索，不能替代完整笔顺示范；最终对错仍需看孩子在纸上独立书写的字，不能把点过“认识”当成默写掌握。

附录的《笔画名称表》《常用偏旁名称表》已整理到 `public/data/references.json`，用作课本查检资料，不把全部附录笔画或偏旁额外生成逐日必默写任务。逐课 notes 已覆盖教材三处书写提示中的六类笔顺规则及相关偏旁识字方法。


## 附录与语境读音补充核验

`references.json` 包含 32 个笔画、29 个常用偏旁，保留印刷第 109—110 页的栏目顺序：先读左栏，再读右栏。符号用 Unicode 文字表示，并非复制教材美术字形；应与示范字、完整笔顺结合观察，不能只看某款字体的孤立符号判断收笔。横斜钩以 ⺄ 示意、竖折撇以 ㄣ 示意，避免较新编码在常见设备上缺字。名称区分了横折弯、横折折、横折弯钩、横斜钩，及竖折折、竖折撇等易混项目。Unicode 笔画名称及字符编码另参考 [Unicode 官方 CJK Strokes 字符表](https://www.unicode.org/charts/PDF/U31C0.pdf)。

根代理在当前人教社官方页面直接可视核验了 [印刷第 110 页偏旁表](https://book.pep.com.cn/1211001101241/files/mobile/116.jpg?260811094231)，确认 29 个名称与顺序。例字按当前页面记录，其中单人旁“作、伴”、言字旁“说、话”、口字旁“叶、吗”与辅助 PDF 的对应例字不同，采用当前官网内容。第 109 页笔画名称与先前已经打开核验的官方页面及辅助 PDF 的 32 项相同。
